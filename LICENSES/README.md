# Bundled third-party license texts

This directory accompanies the frozen Windows payload for Transcriber 9000
`1.0.0-rc.1`. It contains license and notice files for components verified in
the PyInstaller analysis and for native runtime files shipped beside the
application. `THIRD_PARTY_NOTICES.md` is the component/version/source index.

This is a minimum public-RC notice bundle, not an enterprise SBOM. The bundled
FFmpeg is the pinned BtbN `win64-lgpl` build documented in
`packaging/FFMPEG_PROVENANCE.md`; its LGPLv3 text is included here and its
exact source/build-recipe reference package is prepared beside the installer.
