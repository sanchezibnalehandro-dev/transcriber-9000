# Транскрибатор 9000

Локальное Windows-приложение для расшифровки аудио и видео через Whisper. Интерфейс на русском, исходные файлы остаются на компьютере, результаты сохраняются в `output`.

## Быстрый запуск

1. Запустите `Транскрибатор 9000.cmd` двойным кликом.
2. Выберите файл или перетащите его в выделенную область окна приложения.
   Приложение безопасно скопирует аудио или видео в `input`; исходный файл останется на месте.
   Если файл уже находится в `input`, он будет выбран без копирования.
3. При совпадении имени с другим файлом в `input` переименуйте исходный файл: приложение не перезаписывает его молча.
4. Выберите язык, качество и формат результата.
5. Нажмите `Запустить расшифровку`.
6. После завершения откройте `output`.

## Что умеет приложение

- TXT-транскрипт.
- SRT-субтитры с таймкодами.
- Проверка готовности: Whisper, ffmpeg, CUDA/GPU и установленные модели.
- Менеджер моделей Whisper: `tiny`, `base`, `small`, `medium`, `large-v3`.
- Защита от молчаливой перезаписи существующих результатов.

## Режимы качества

- `tiny` - самый быстрый черновик.
- `base` - хороший минимум.
- `small` - режим для большинства задач.
- `medium` - точнее, лучше использовать с GPU.
- `large-v3` - максимальное качество, может работать долго.

Если CUDA доступна, приложение использует NVIDIA GPU. Если CUDA недоступна, Whisper работает на CPU, но тяжёлые модели будут медленными.

## Правила проекта

- Исходные материалы для расшифровки берутся только из `input`; перетащенные или выбранные извне файлы сначала копируются туда.
- Результаты пишутся только в `output`.
- Аудио и видео не отправляются во внешние сервисы.
- Скачивание из сети используется только для моделей Whisper и только по явному нажатию в приложении.
- Исходные файлы не удаляются, не перемещаются и не изменяются.

Смотрите [SETUP.md](SETUP.md).

В репозиторий не кладутся `.venv`, `.cache`, модели `*.pt`, `input`, `output` и локальные бинарные файлы ffmpeg.

## Файлы

- `topgun_minimal_app.py` - основной интерфейс «Транскрибатор 9000».
- `topgun_razbor.py` - ядро локальной транскрибации.
- `topgun_razbor_gui.ps1` - старый WinForms GUI, оставлен как fallback.
- `Транскрибатор 9000.cmd` - запуск двойным кликом.
