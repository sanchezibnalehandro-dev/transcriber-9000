# Транскрибатор 9000

Локальное Windows-приложение для расшифровки аудио и видео через Whisper. Интерфейс на русском, исходные файлы остаются на компьютере, результаты сохраняются в `output`.

## Быстрый запуск

1. Запустите `Транскрибатор 9000.cmd` двойным кликом.
2. Выберите аудио или видео либо перетащите файл в окно.
3. Если файл находится вне `input`, приложение безопасно скопирует его туда. Оригинал останется на месте.
4. Выберите язык, качество и формат результата.
5. Нажмите `Запустить расшифровку`.
6. Готовые файлы появятся в `output`.

## Что умеет приложение

- TXT-транскрипт.
- SRT-субтитры с таймкодами.
- Локальная обработка через Whisper без отправки аудио и видео во внешние сервисы.
- Автоматическое использование NVIDIA GPU через CUDA, если он доступен.
- Проверка окружения: Python, Whisper, ffmpeg, устройство и установленные модели.
- Менеджер моделей Whisper: `tiny`, `base`, `small`, `medium`, `large-v3`.
- Drag & drop аудио и видео.
- Безопасный импорт файлов в `input` без изменения оригинала.
- Защита от молчаливой перезаписи существующих файлов.

## Как приложение устроено

Здесь две основные части:

- `transcriber_app.py` — окно приложения, кнопки, drag & drop, скачивание моделей и отображение статуса.
- `transcriber_core.py` — собственно обработка файла через Whisper и сохранение TXT/SRT.

Когда пользователь запускает расшифровку, интерфейс запускает `transcriber_core.py` отдельным процессом. Поэтому тяжёлая работа Whisper не выполняется внутри окна приложения и не должна блокировать сам интерфейс.

Для каждого запуска служебные файлы статуса и результата создаются внутри `.cache/transcriber/runs`. Это временные технические данные; в GitHub они не попадают.

## Режимы качества

- `tiny` — самый быстрый черновик.
- `base` — хороший минимум.
- `small` — режим для большинства задач.
- `medium` — точнее, лучше использовать с GPU.
- `large-v3` — максимальное качество, может работать долго.

Если CUDA доступна, приложение использует NVIDIA GPU. Если CUDA недоступна, Whisper работает на CPU, но тяжёлые модели будут заметно медленнее.

## Правила работы с файлами

- Whisper получает исходные материалы только из `input`.
- Если пользователь выбирает файл в другом месте, GUI сначала копирует его в `input`.
- Результаты записываются только в `output`.
- Аудио и видео не отправляются во внешние сервисы.
- Сеть используется только при явном скачивании моделей Whisper.
- Исходные файлы не удаляются, не перемещаются и не изменяются.
- Существующие результаты не перезаписываются молча.
